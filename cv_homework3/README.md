# 图像几何特征提取与可视化

这个项目实现了图像几何特征的提取和可视化，包括围盒、凸包和最小包围盒的计算与显示

## 功能特点

- 支持任意尺寸的灰度图像输入
- 自动进行图像二值化处理
- 提取图像中的几何特征：
  - 围盒（轴对齐包围盒）
  - 凸包
  - 最小包围盒（旋转卡壳法）
- 可视化所有几何特征
- 支持批量处理多个图像

## 项目结构

```
.
├── origin_img/          # 原始图像目录
├── result_img/          # 结果图像目录
├── src/                 # 源代码目录
│   ├── main.cpp        # 主程序
│   ├── image.h         # 图像处理类声明
│   ├── image.cpp       # 图像处理类实现
│   ├── point.h         # 点和几何计算类
│   ├── get_img.py      # 图像预处理脚本
│   ├── vis_geometry.py # 几何特征可视化脚本
│   └── run_geometry.sh # 批处理脚本
└── README.md           # 项目说明文档
```

## 依赖项
- Linux
- C++编译器（支持C++11或更高版本）
- Python 3.x
- OpenCV (cv2)
- NumPy
- Matplotlib

## 使用方法

1. 将待处理的图像放入`origin_img`目录

2. 运行批处理脚本：
```bash
chmod +x src/run_geometry.sh
./src/run_geometry.sh
```

3. 查看结果：
- 结果图像将保存在`result_img`目录下
- 每个输入图像会生成三个结果文件：
  - `{filename}_hull.png`: 显示凸包（蓝色）
  - `{filename}_minbox.png`: 显示最小包围盒（黄色）
  - `{filename}_box.png`: 显示最大外接矩形（绿色）

## 处理流程

1. 图像预处理：
   - 读取原始图像
   - 转换为灰度图
   - 进行二值化处理

2. 特征提取：
   - 计算最大外接矩形
   - 计算凸包
   - 计算最小包围盒

3. 可视化：
   - 在原图上绘制各个几何特征
   - 使用不同颜色区分不同特征
   - 保存可视化结果
